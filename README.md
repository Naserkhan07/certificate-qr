# certificate-qr

Certificate images served via GitHub Pages so the QR codes on the certificates
open the certificate in a phone browser when scanned.

Files placed at the repo root become public at:
  https://naserkhan07.github.io/certificate-qr/<filename>

⚠️ **Privacy warning:** this repository (and its Pages site) is **public**.
Anything uploaded — including certificate images that may contain Aadhaar
numbers, names and photos — can be viewed/accessed by anyone with the link and
may be indexed by search engines. Upload only images you are comfortable being
public. For private data, use Google Drive / a private host instead (the bot's
CSV payload mode supports custom links).
